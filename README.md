# Forma — AI Weight Control Coach

A calm, mobile-first decision-support dashboard designed to help users pause before eating, understand their remaining energy budget, and build sustainable habits.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js 15 and React 19
- TypeScript
- Custom responsive CSS
- Lucide icons

## Deployment

Automatically deployed with Vercel from the `main` branch.
